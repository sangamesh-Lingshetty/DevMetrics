DevInsights – Developer Productivity Analytics SaaS
Built a full-stack multi-tenant SaaS platform that connects with GitHub to analyze engineering productivity, code quality, and team collaboration metrics in real-time. Designed a serverless architecture using AWS Lambda, DynamoDB, and API Gateway with a React + Next.js dashboard. Integrated OAuth, Stripe billing, and WebSocket-based live analytics. Enables engineering managers to identify bottlenecks, burnout risks, and sprint inefficiencies through intelligent data visualization and alerts.
